# Idle Hamster

Simple gnome extension to tell [hamster](https://github.com/projecthamster/hamster) to stop tracking tasks when the user is idle

![screenshot](https://extensions.gnome.org/extension-data/screenshots/screenshot_8457.png)

## Installation

Easiest way to install is via [E.G.O.](https://extensions.gnome.org/extension/8457/idle-hamster/)

Can install from dev by cloning this repo and running:
```bash
make install
```
